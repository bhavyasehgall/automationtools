# AutomationTools

🚀 **AutomationTools** is a Bash-based reconnaissance automation suite designed to simplify penetration testing workflows. It integrates **Nmap scanning**, **subdomain enumeration**, and **directory discovery** into a single, easy-to-use toolkit.

---

## Features

- **Nmap Scanner**
  - Perform automated network scans
  - Detect open ports and services
  - Option to customize scan types

- **Subdomain Enumeration**
  - Automate discovery of subdomains for a target domain
  - Combine multiple sources for more complete results

- **Directory Discovery**
  - Scan websites for hidden directories and files
  - Supports common wordlists and custom lists
